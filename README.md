# 🌙 Dream Diary Bot

Telegram-бот для ведения дневника сновидений. Записывайте сны текстом или голосом, просматривайте и ищите их, редактируйте и получайте автоматическую карту повторяющихся тем.

## Возможности

- **Запись снов** — название, описание и дата; можно надиктовать голосом.
- **Список и поиск** — пагинация, регистронезависимый поиск по названию и описанию, включая кириллицу.
- **Редактирование и удаление** — с подтверждением перед удалением.
- **Карта снов** — ИИ находит повторяющиеся образы и сюжеты в записях.
- **Изоляция данных** — каждый пользователь видит только свои сны.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Главное меню |
| `/help` | Справка по командам |
| `/add` | Записать новый сон |
| `/list` | Список снов с пагинацией |
| `/search <слова>` | Поиск по названию и описанию |
| `/map` | Показать последнюю карту снов |
| `/edit <#N или название>` | Редактировать сон |
| `/delete <#N или название>` | Удалить сон |
| `/cancel` | Отменить текущий ввод |

Все команды доступны и через кнопки главного меню.

## Как работает карта снов

Когда в дневнике накапливается достаточно записей, бот периодически отправляет их в языковую модель и сохраняет найденные повторяющиеся паттерны. Карта обновляется не чаще раза в две недели и только при появлении новых снов. Команда `/map` показывает последнюю готовую карту из кэша и не тратит токены.

## Приватность

Сны хранятся в локальной SQLite-базе и разделены по `user_id`. Для построения карты текст записей отправляется в ZvenoAI; голосовые сообщения распознаются локально. Секреты, базы данных и ключи исключены из репозитория.

## Технологии

Python, `python-telegram-bot`, SQLite, `faster-whisper`, ZvenoAI.
